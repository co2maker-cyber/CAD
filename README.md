# Draftline CAD

브라우저에서 동작하는 2D 스케치 + 3D 솔리드 모델링 CAD입니다. 설치 없이 실행되며 단위는 mm입니다.

- 바로 쓰기: https://co2maker-cyber.github.io/CAD/
- 파일 구성: `draftline.html`(앱·2D 스케치), `model3d.js`(3D 모델 작업공간), `index.html`(GitHub Pages 진입점)

상단의 **스케치 / 모델** 전환으로 작업공간을 바꿉니다. 도면과 모델은 브라우저 localStorage에 자동 저장됩니다.

## 스케치 (2D)

| 구분 | 도구 | 단축키 |
|---|---|---|
| 그리기 | 선, 폴리선, 사각형, 원 | L, P, R, C |
| | 원호 (3점: 시작점 → 지나는 점 → 끝점) | A |
| | 치수 (정렬 치수) | D |
| 수정 | 오프셋 — 숫자로 거리 지정, 대상 선택 후 만들 쪽 클릭 | O |
| | 자르기 — 지울 부분 클릭, 다른 객체와의 교차점까지 잘림 | T |
| | 모깎기 — 숫자로 반지름 지정, 선 두 개 선택 (R 0은 모서리 맞춤) | F |
| | 분해 — 사각형·폴리선을 선으로 | X |
| 편집 | 선택·이동·그립 편집·복제·삭제 | V, Ctrl+D, Delete |
| | 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 보기 | 전체 보기, 휠 확대, 가운데 버튼·Space+끌기로 이동 | Z |

- **3D 돌출 (E)**: 스케치에서 고른 닫힌 도형(고른 게 없으면 전체)을 바로 3D 돌출합니다. 안쪽 도형은 구멍으로 남습니다.
- **참고 이미지**: 사진·도면 이미지를 밑그림으로 깔고(위치·폭·투명도 조절) 따라 그릴 수 있고, 3D 바닥에도 같이 보입니다.

좌표 입력: `50`(커서 방향 길이), `20,30`(절대), `@30,0`(상대), `@50<30`(길이<각도).
스냅: GRID(F7), SNAP(F9), ORTHO(F8, Shift로 임시 반전), OSNAP(F3: 끝점·중간점·중심·사분점).

## 모델 (3D)

### 빠른 모델링 (도형 놓고 끌기)

- **도형 패널**: 상자·원통·구·원뿔·토러스·쐐기·피라미드·튜브·반구·이미지. 누르면 치수(규격)를 먼저 입력하고, 반투명 미리보기를 보면서 화면을 클릭해 놓습니다. 다른 바디 윗면을 클릭하면 그 위에 올라갑니다. 화면으로 끌어다 놓으면 기본 크기로 바로 놓입니다.
- **크기·회전 손잡이**: 바디를 하나 고르면 흰 상자(옆면 4·모서리 4·위 1)로 크기를, 빨강·초록·파랑 고리로 X·Y·Z축 회전을 바꿉니다. 크기는 그리드에 맞춰지고 Shift로 비율 유지, 회전은 15° 단위(Shift 1°).
- **이미지 입체**: 사진의 밝기를 높이로 바꾼 부조(리소페인)를 만듭니다. 폭·바닥 두께·최대 높이·어두운 곳을 높게 여부를 정할 수 있습니다.
- **화면 조작**: 왼쪽 빈 곳 끌기·휠 클릭 끌기로 회전, 오른쪽 끌기로 이동, 휠로 확대.
- **직접 옮기기**: 바디를 끌면 바닥과 나란히 움직입니다(그리드 스냅 0.1~10 mm). 방향키로 조금씩(Shift ×10), PgUp/PgDn(또는 Ctrl+↑↓)으로 위아래, **D**로 바닥에 내려놓기.
- **솔리드/구멍**: 바디마다 솔리드와 구멍(**H**)을 바꿀 수 있고, 여러 개를 Shift+클릭으로 고른 뒤 **그룹(Ctrl+G)**하면 솔리드는 합쳐지고 구멍은 빠집니다.
- **여러 개 선택**: Shift+클릭, Ctrl+A. 선택 범위 기준 정렬(X·Y·Z 각각 최소/가운데/최대), **복제(Ctrl+D)**, 지우기(Delete).
- **빠른 치수 편집**: 기본 도형을 고르면 오른쪽 패널에서 크기·위치를 바로 고칩니다.
- 옮기기·정렬·바닥에 놓기는 타임라인 맨 끝의 **배치** 피처 하나에 모여 기록되므로 Ctrl+Z로 되돌리거나 나중에 값을 고칠 수 있습니다.

### 파라메트릭 피처

Fusion 360처럼 **스케치 프로파일 → 피처 → 솔리드 바디** 순서로 모델을 만들고, 모든 피처가 하단 **타임라인**에 쌓입니다. 타임라인의 피처를 누르면 값을 고칠 수 있고, 스케치를 바꾸면 모델이 다시 계산됩니다(파라메트릭).

| 구분 | 피처 | 설명 |
|---|---|---|
| 만들기 | 돌출 (E) | 스케치의 닫힌 영역을 거리만큼 밀어 올림. 한 방향/대칭, 스케치 평면(XY·XZ·YZ)과 간격 지정 |
| | 회전 | 프로파일을 스케치 X축·Y축 또는 고른 선을 축으로 회전 (부분 각도 가능) |
| | 상자·원통·구·원뿔·토러스 | 치수와 위치로 기본 도형 생성 |
| 작업 | 새 바디 / 결합 / 잘라내기 / 교차 | 만들기 피처마다 대상 바디와의 불리언 연산 선택 |
| 수정 | 결합 | 바디끼리 더하기·빼기·교차 (도구 바디 남기기 선택) |
| | 이동 | 바디 이동·회전 |
| | 패턴 | 직사각형 배열 또는 Z축 원형 배열 |
| | 대칭 | YZ·XZ·XY 평면 기준 대칭 복사 (원본과 합치기 선택) |
| | 분할 | 평면으로 바디를 두 개로 나누기 |
| | 모깎기 | 3D 모서리를 반지름만큼 둥글게. 화면에서 직선·원형(구멍·보스 테두리) 모서리를 클릭해 고름. 안쪽(오목) 모서리는 살을 채움 |
| | 모따기 | 3D 모서리를 거리만큼 비스듬히 깎음 (같은 방식으로 모서리 선택) |
| | 쉘 | 속을 비우고 벽 두께만 남김. 방향: 안쪽(바깥 크기 유지)·바깥쪽(안쪽 크기 유지)·양쪽. 화면에서 평평한 면을 클릭하면 그 면이 열림(컵·상자 모양) |
| | 지우기 (Delete) | 선택한 바디를 지움. 타임라인에 지우기 피처로 남아 Ctrl+Z나 피처 삭제로 되돌릴 수 있음 |
| 검사 | 측정 (M) | 모델 표면의 두 점 사이 거리·ΔX·ΔY·ΔZ |
| | 물리 속성 | 바디 선택 시 부피·표면적·질량(재질별 밀도)·크기·무게중심 |
| | 단면 | X·Y·Z 방향 단면 보기와 위치 슬라이더 |
| 보기 | 등각·위·앞·우측·화면 맞춤, 표시 모드(음영+모서리·음영·반투명·와이어프레임) | F: 화면 맞춤 |
| 내보내기 | STL(3D 프린팅), OBJ | 선택한 바디 또는 보이는 바디 전체 |

프로파일은 사각형·원·닫힌 폴리선, 그리고 끝점이 맞닿은 선·원호를 이은 닫힌 윤곽에서 자동으로 찾습니다. 안쪽 윤곽은 구멍으로 처리됩니다.

## 파일

- **DXF 내보내기**(스케치): AutoCAD R12 형식 (LINE, CIRCLE, ARC, TEXT)
- **저장 / 열기**: JSON 하나에 스케치와 3D 모델(피처·바디 설정)을 함께 보관
- GitHub Pages에서는 내보내기 창의 **파일로 저장** 버튼으로 바로 내려받을 수 있습니다.

## 기술 메모

- 3D: [three.js](https://threejs.org) 0.160, 불리언 연산은 [three-bvh-csg](https://github.com/gkjohnson/three-bvh-csg) — jsDelivr CDN에서 불러오므로 모델 작업공간은 인터넷 연결이 필요합니다.
- 바디는 삼각형 메시(CSG) 기반입니다. 3D 모깎기·모따기는 고른 모서리를 따라 원호·삼각형 단면의 도구를 만들어 빼거나(볼록) 더해서(오목) 구현합니다.
- 쉘, 구속조건 스케치, 곡면 모서리(원형이 아닌 곡선) 모깎기처럼 B-rep 커널이 필요한 기능은 아직 없습니다.

## 제한 사항

- 2D 모깎기는 선끼리만 됩니다. 사각형·폴리선은 먼저 X로 분해하세요.
- 스케치는 하나이며, 피처마다 그 스케치를 놓을 평면(XY·XZ·YZ)과 간격을 고릅니다.
- 3D 모깎기·모따기는 모서리마다 따로 깎기 때문에, 세 모서리가 만나는 꼭짓점은 구면으로 매끄럽게 섞이지 않고 각진 상태로 남습니다. 이미 모깎기한 모서리 옆 모서리는 남은 직선 구간만 처리됩니다.
- 쉘은 표면을 두께만큼 안쪽으로 옮긴 형상을 빼서 만듭니다. 두께가 바디의 얇은 부분 절반보다 두꺼우면 결과가 깨질 수 있고, 모깎기된 면 옆을 열면 그 테두리는 얇아집니다.
- 3D 모서리는 원형 외의 곡선(스플라인·타원 등)은 고를 수 없습니다.
- 스케치 객체를 지우거나 자르기로 바꾸면 그 객체를 참조하던 피처가 타임라인에서 빨갛게 표시됩니다. 피처를 열어 프로파일을 다시 고르면 됩니다.
