# Draftline CAD

브라우저에서 동작하는 2D CAD입니다. 설치 없이 `draftline.html` 파일 하나로 실행됩니다. 단위는 mm입니다.

## 실행

`draftline.html`을 브라우저로 열면 됩니다. 도면은 브라우저 localStorage에 자동 저장됩니다.

## 기능

| 구분 | 도구 | 단축키 |
|---|---|---|
| 그리기 | 선, 폴리선, 사각형, 원 | L, P, R, C |
| | 원호 (3점: 시작점 → 지나는 점 → 끝점) | A |
| | 치수 (정렬 치수) | D |
| 수정 | 오프셋 — 숫자로 거리 지정, 대상 선택 후 만들 쪽 클릭 | O |
| | 자르기 — 지울 부분 클릭, 다른 객체와의 교차점까지 잘림 | T |
| | 모깎기 — 숫자로 반지름 지정, 선 두 개 선택 (R 0은 모서리 맞춤) | F |
| | 분해 — 사각형·폴리선을 선으로 | X |
| 편집 | 선택·이동·그립 편집·복제·삭제 | V, Ctrl+D, Delete |
| | 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 보기 | 전체 보기, 휠 확대, 가운데 버튼·Space+끌기로 이동 | Z |

### 좌표 입력

그리는 도중 숫자를 입력하면 하단 명령줄로 들어갑니다.

- `50` — 커서 방향으로 길이 50
- `20,30` — 절대 좌표 (사각형 두 번째 점은 폭,높이)
- `@30,0` — 상대 좌표
- `@50<30` — 길이 50, 각도 30°

### 스냅

GRID(F7), 그리드 스냅 SNAP(F9), 직교 ORTHO(F8, Shift로 임시 반전), 객체 스냅 OSNAP(F3: 끝점·중간점·중심·사분점).

### 파일

- **DXF 내보내기**: AutoCAD R12 형식 (LINE, CIRCLE, ARC, TEXT). AutoCAD, LibreCAD, FreeCAD에서 열 수 있습니다.
- **저장 / 열기**: JSON 형식으로 도면 전체를 보관하고 다시 불러옵니다.

## 제한 사항

- 모깎기는 선(LINE)끼리만 됩니다. 사각형·폴리선은 먼저 X로 분해하세요.
- 자르기는 치수 객체를 대상으로 하지 않으며, 폴리선을 자르면 열린 폴리선으로 바뀝니다.
- 사각형 오프셋은 바깥쪽도 직각 모서리로 만들어집니다.
